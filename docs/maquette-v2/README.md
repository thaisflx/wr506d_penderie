# Maquette v2 Lendly (mobile 390 px)

Référence visuelle validée pour la refonte du front.

- `png/` : capture de chaque écran (390 × 844, en x2). Guide.png = palette, typographie et composants.
- `html/` : code HTML/CSS de chaque écran, pour reprendre les valeurs exactes (couleurs, tailles, rayons, espacements, masque `.scallop`, forme fleur en SVG, ligne décorative). Ouvrir dans un navigateur : les liens entre écrans fonctionnent.
- `html/MonoScribble.ttf` : police des titres (démo, sans chiffres : ils passent en Bricolage Grotesque via `unicode-range`).

Ce sont des maquettes statiques : les formes colorées remplacent les vraies photos, les données sont fictives.
